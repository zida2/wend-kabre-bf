## 📚 7 NOUVEAUX CONTENUS DÉTAILLÉS

### 1. **SOUMISSION** 📤

**Questions détectées** :
- "Comment soumettre ?"
- "Où déposer mon dossier ?"
- "Comment participer ?"
- "Candidater comment ?"

**Réponse couvre** :
- Où déposer (adresse, plateforme électronique)
- Quand déposer (avant limite, conseil 24h avance)
- Comment présenter (enveloppe fermée, mentions)
- Contenu (admin + technique + financière)

---

### 2. **GARANTIES** 🏦

**Questions détectées** :
- "C'est quoi une caution ?"
- "Garantie bancaire obligatoire ?"
- "Combien pour la caution ?"

**Réponse couvre** :
- Caution de soumission (1-3%, avec offre)
- Caution de bonne exécution (5-10%, après signature)
- Qui peut délivrer (banques, assurances)
- Forme acceptée (attestation originale)

---

### 3. **EVALUATION** 📊

**Questions détectées** :
- "Comment sont notées les offres ?"
- "Critères d'évaluation ?"
- "Comment ils choisissent ?"

**Réponse couvre** :
- Étape 1 : Administrative (conformité)
- Étape 2 : Technique (barème 100 points)
- Étape 3 : Financière (moins-disant qualifié)
- Méthodes de sélection (80/20 ou prix seul)

---

### 4. **RESULTATS** 🏆

**Questions détectées** :
- "Quand les résultats ?"
- "Comment savoir si j'ai gagné ?"
- "Qui a été retenu ?"

**Réponse couvre** :
- Publication résultats (30-60 jours)
- Si retenu (caution, signature, démarrage)
- Si pas retenu (débrief, amélioration, recours)
- Restitution caution

---

### 5. **RECLAMATIONS** ⚖️

**Questions détectées** :
- "Comment contester ?"
- "Je ne suis pas d'accord"
- "Recours possible ?"

**Réponse couvre** :
- Délais (10-15 jours)
- Motifs valables
- Procédure (admin → ARCOP → tribunal)
- Conseils pratiques

---

### 6. **THANKS** 😊

**Questions détectées** :
- "Merci"
- "Cool"
- "Super"
- "Parfait"

**Réponse** : Variations aléatoires sympathiques
- "De rien ! Je suis là pour ça..."
- "Avec plaisir ! Si vous avez besoin..."
- "Content d'avoir pu vous aider !..."

---

### 7. **GOODBYE** 👋

**Questions détectées** :
- "Au revoir"
- "Bye"
- "À plus"
- "Ciao"

**Réponse** : Variations sympathiques
- "Au revoir ! Bonne chance..."
- "À bientôt ! N'hésitez pas..."
- "Salut ! Bon succès..."

## 🎭 RÉPONSES SITUATIONNELLES

Le système détecte maintenant les **émotions et situations** :

### Confusion détectée
**Questions** : "Je sais pas", "C'est quoi", "Confus"

**Réponse** : Menu guidé complet + encouragement

---

### Frustration/Difficulté
**Questions** : "C'est difficile", "Compliqué", "Galère"

**Réponse** : Décomposition en 5 étapes simples + empathie

---

### Échec/Rejet
**Questions** : "J'ai perdu", "Refusé", "Pas retenu"

**Réponse** : 
- Raisons courantes d'échec (60/30/10%)
- Actions concrètes à mener
- Encouragement à continuer

---

### "Comment gagner"
**Questions** : "Gagner", "Réussir", "Tips", "Astuces"

**Réponse** : 5 conseils clés
1. Dossier impeccable
2. Offre technique solide
3. Prix compétitif mais réaliste
4. Présentation professionnelle
5. Anticipation

---

### Questions sur coûts
**Questions** : "Ça coûte combien", "Frais", "Payer"

**Réponse** : 
- Frais obligatoires (DAO, cautions, timbres)
- Frais facultatifs (consultant, traductions)
- Ce qui est gratuit (consultation, dépôt, ARCOP)

---

### Marché spécifique mentionné
**Questions** : "Un marché", "Mon marché", "Ce marché"

**Réponse** : Demande 3 précisions
1. Le montant
2. Le type (travaux/fournitures/services)
3. Le besoin (documents/offre/délais)
