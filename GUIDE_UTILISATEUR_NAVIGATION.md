### 🔍 Fonction de Recherche

**Comment rechercher un sujet spécifique :**

1. Cliquez sur le bouton **"🔍 Rechercher"** en haut de la page
2. Une barre de recherche apparaît
3. Tapez un mot-clé (exemples : "RCCM", "Garantie", "ASF", "Pièces", "Délais")
4. Les chapitres correspondants s'affichent instantanément

**Exemples de recherches utiles :**
- `RCCM` → Trouve le chapitre sur les pièces administratives
- `Garantie` → Trouve les chapitres sur la garantie de soumission
- `Délais` → Trouve les chapitres sur les délais de dépôt
- `Paiement` → Trouve le chapitre sur les délais de paiement
- `Recours` → Trouve le chapitre sur les voies de recours

### 📖 Navigation Entre les Chapitres

**3 façons de naviguer :**

#### 1. Via la Table des Matières (Recommandé)
```
Cliquez sur n'importe quel chapitre dans la liste de gauche
→ Le contenu s'affiche immédiatement à droite
```

#### 2. Via les Boutons de Navigation
```
[← Page Précédente]          [Page Suivante →]
        ↑                              ↑
   Chapitre 2                    Chapitre 4
  (depuis Ch. 3)                (depuis Ch. 3)
```

#### 3. Via les Points de Progression
```
● ● ○ ○ ○ ○ ○
↑
Vous êtes au chapitre 2
Cliquez sur n'importe quel point pour sauter à ce chapitre
```

## ❓ FAQ Navigation

### Q : Le guide fonctionne-t-il sur mobile ?
**R :** Oui ! Le design s'adapte automatiquement. Sur mobile, les deux pages s'affichent l'une en dessous de l'autre.

### Q : Puis-je revenir en arrière facilement ?
**R :** Oui, 3 options :
1. Bouton "Page Précédente"
2. Cliquer sur un chapitre dans la table des matières
3. Utiliser les points de navigation

### Q : La recherche cherche dans tout le contenu ?
**R :** Non, elle cherche uniquement dans les titres des chapitres. C'est plus rapide et précis.

### Q : Puis-je imprimer le guide ?
**R :** Actuellement non, mais vous pouvez consulter chaque chapitre et prendre des notes. Une version PDF pourrait être ajoutée plus tard.

### Q : Le guide est-il à jour ?
**R :** Oui, il est conforme aux textes 2024/2025 :
- Loi n°005-2024/ALT du 20 avril 2024
- Décret n°2024-1748 du 31 décembre 2024
- Arrêté n°2025-0323
