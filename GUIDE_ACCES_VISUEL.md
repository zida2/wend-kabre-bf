## 🎨 Design System Utilisé

### Couleurs :
- **Primary** : `#064E3B` (vert foncé)
- **Primary Dark** : Variante plus sombre
- **Primary Muted** : `rgba(6,78,59,0.1)`
- **Success Muted** : `rgba(5,150,105,0.1)`

### Gradients :
- **Principal** : `linear-gradient(135deg, var(--primary) 0%, var(--primary-dark) 100%)`
- **Secondaire** : `linear-gradient(135deg, var(--primary-muted) 0%, var(--success-muted) 100%)`
- **Séparateur** : `linear-gradient(90deg, var(--primary) 0%, var(--accent) 100%)`

### Shadows :
- **Subtle** : `0 4px 12px rgba(6,78,59,0.1)`
- **Medium** : `0 8px 32px rgba(0,0,0,0.08)`
- **Strong** : `0 20px 60px rgba(6,78,59,0.2)`

### Borders :
- **Left (Table)** : `8px solid var(--primary)`
- **Right (Content)** : `8px solid var(--accent)`
- **Cards** : `1px solid var(--color-border)`
- **Active** : `2px solid var(--primary)`

### Spacing :
- **Padding Hero** : `clamp(40px, 8vw, 80px) clamp(24px, 5vw, 60px)`
- **Gap Grid** : `32px`
- **Margin Bottom** : `48px` (sections)
